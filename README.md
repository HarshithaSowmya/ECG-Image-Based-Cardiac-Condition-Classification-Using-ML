# ECG Image-Based Cardiac Condition Classification Using ML

## Complete project, datasets and preprocessing outputs

Open **Full-Project/** for the complete research project. It contains the original
`dataset`, `ECG_IMAGES_DATASET`, `training`, `preproceed_images`, `preprocessed_1d`,
`Combined1d_csv`, `Final_Dataset`, models and the updated app code.

Original Git LFS references were restored from the original public source and
verified against their SHA-256 hashes. See `Full-Project/FULL_PACKAGE_REPORT.json`
for exact restored counts and any legacy demo references that remain unavailable.

Read `Full-Project/START_HERE_FULL_PROJECT.md` for installation and run commands.
Install `requirements-training.txt` to use the training scripts.

**ECG-Project-Updated/** remains the smaller Vercel application. Keep the Vercel
root directory set to `ECG-Project-Updated` so research datasets are not deployed.
The existing top-level **Deployment/** folder is unchanged.
