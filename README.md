# ECG Image-Based Cardiac Condition Classification Using ML

**Open Full-Project/** for the complete application and research project.
It contains the frontend, backend, validation and preprocessing code, trained
models, original ECG datasets, training scripts and preprocessing outputs.

Download this branch as a ZIP, extract it, and open **Full-Project** in VS Code.
Follow [START_HERE_FULL_PROJECT.md](Full-Project/START_HERE_FULL_PROJECT.md) for
installation, running the app and training instructions.

## Vercel deployment

Set the Vercel project's **Root Directory** to **Full-Project** in
Settings > Build and Deployment, then redeploy. This folder includes vercel.json
and .vercelignore to exclude datasets, training outputs and legacy demo files
from the deployed inference app. The former duplicate top-level Deployment and
ECG-Project-Updated folders have been removed.

Restored research output files were verified against the original SHA-256
references. See [FULL_PACKAGE_REPORT.json](Full-Project/FULL_PACKAGE_REPORT.json)
for details, including 17 unavailable legacy demo references.
